# Release Notes

::: tip
The maintenance period for version **v4.0.z** is from April 8, 2025 to Dec 8, 2026.
:::

:::note
Starting with `v4.0.17`, the default subscription channel for this bundle changes from `latest` to `stable`. Both channels carry the same `v4.0.z` patch stream on the 4.0 LTS line, so existing Subscriptions on `channel: latest` continue to work with no action required. To opt out of the new default explicitly, keep `channel: latest` in your Subscription YAML.
:::

## v4.0.18

### New and Optimized Features

**Tekton Hub**

- Fresh installations no longer deploy the in-cluster Tekton Hub by default; the Hub capability is provided through the [ArtifactHub Shim](../hub/configure/configuring-artifacthub-shim.mdx). When **upgrading** from an earlier `v4.0.x` release that had Tekton Hub deployed, the existing Tekton Hub component and its catalog artifacts are now **preserved and remain usable**, so existing Task and Pipeline references continue to resolve. Both the fresh-install and upgrade paths work in air-gapped environments. During an upgrade the operator records the catalog image already running in your environment and pins it, and it retains the existing catalog `ConfigMap`s so they are not garbage-collected.
- A new operator-level environment variable `AUTOINSTALL_TEKTONHUB` (set on the operator Deployment) controls Tekton Hub management with three values: `preserve` (default - keep an existing Hub, and do not deploy one on a fresh install), `true` (explicitly deploy and keep the Hub, for the `all` profile), and `false` (explicitly remove any existing Hub - destructive, opt-in only). Any unset or unrecognized value is treated as `preserve`.

### Breaking Changes

Fresh installations no longer deploy the in-cluster Tekton Hub by default (earlier `v4.0.0` - `v4.0.17` releases deployed it automatically); the Hub capability is now served through the ArtifactHub shim. Existing environments are not affected: an upgrade retains its existing Tekton Hub and catalog instead of removing them, so existing Task and Pipeline references continue to resolve. See the [upgrade guide](../upgrade.mdx) for upgrade and verification steps.

- Tekton Pipelines

- Tekton Results

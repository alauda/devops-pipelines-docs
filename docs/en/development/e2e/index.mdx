# E2E Testing

This section provides comprehensive documentation for end-to-end (E2E) testing in the TektonCD Operator project.

## What is E2E Testing?

End-to-end testing validates the complete functionality of the TektonCD Operator in a real Kubernetes environment. These tests ensure that all components work together correctly and that the system behaves as expected from an end-user perspective.

## Documentation Overview

The E2E testing documentation is organized into the following sections:

- **[Writing Guidelines](./guidelines.md)** - Best practices and conventions for writing E2E tests
- **[Running Tests](./run_e2e.mdx)** - Guide on how to run E2E tests locally

## Built-in Integration Tests

### Prerequisites

- The `Tekton Triggers` project and the Tekton Pipelines project must be installed in the Kubernetes cluster.
- The namespace `test-triggers` must exist.
- The runtime environment should have `kubectl` installed and configured with kubeconfig.

### Running Tests

Navigate to the `test` directory in the terminal.

```bash
go test -v ./integration
```

Note: It is necessary to manually clean up the data generated from the tests:

```bash
kubectl delete ns test-triggers
## OR
kubectl -n test-triggers delete eventlistener,triggers,pipelineruns --all
```

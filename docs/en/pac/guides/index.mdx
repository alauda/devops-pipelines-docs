# Guides

End-to-end walkthroughs for connecting a Git repository to PAC: choosing an integration mode, creating the credentials, creating the `Repository` resource, and registering the webhook on the Git provider.

Each guide is self-contained for the provider it covers and references the shared procedures in [How To](../how_to/index.mdx) where they apply to multiple providers.

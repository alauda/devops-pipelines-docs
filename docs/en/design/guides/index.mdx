## Documentation Process

The project follows a structured approach to design documentation:

1. **TEPs (Tekton Enhancement Proposals)**: Used for proposing changes, analyzing problems, and recording decisions
2. **Design Documents**: Authoritative specifications of system behavior and implementation

See the [Documentation Process Guide](documentation-process-guide.mdx) for detailed workflow instructions.

## Contributing Design Documents

When creating new design documents:

1. Follow the [Documentation Process Guide](documentation-process-guide.mdx) for the complete workflow
2. Use the [Documentation Migration Guide](documentation-migration-guide.mdx) for format and structure
3. Use descriptive filenames with kebab-case naming convention
4. Include appropriate frontmatter with weight for ordering
5. Add assets to the shared assets directory

## Migration from Specs Repository

Design documents are being migrated from the separate MkDocs-based specs repository to this centralized location. See the [Documentation Migration Guide](documentation-migration-guide.mdx) for detailed instructions on the migration process.

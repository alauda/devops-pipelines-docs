# ResourceFlavor [kueue.x-k8s.io/v1beta2]

A ResourceFlavor is a cluster-scoped resource referenced by a ClusterQueue's resource groups. An empty flavor is sufficient for the `tekton.dev/pipelineruns` concurrency quota.

The schema describes node labels, taints, tolerations, and topology used by Kueue integrations. Scheduler uses a flavor to obtain quota; its PipelineRun integration does not copy those placement settings into actual execution Pods. Configure Pod placement through Tekton instead. See [Resource Flavors](../../../scheduler/concepts/core_concepts.mdx#resource_flavors) for a minimal example.
